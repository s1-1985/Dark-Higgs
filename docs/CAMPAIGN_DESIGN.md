> 実装はまだ無い。ここは **オーナーの構想の記録** と、そのために先に決めた **勢力の案・デザイン言語** をまとめる。

## 1. コンセプト（オーナーの言葉を整理したもの）

**一行**: 小さな機体から始めて戦闘で稼ぎ、艦を育て、勢力の依頼を受けながらワールドマップの勢力圏を取り合う。
参考: **Mount & Blade**（小さく始めて成り上がる）・**Armored Core**（勢力からの依頼）・**セカンドギャラクシー / EVE**（カスタムの細かさ）。

### 1-1. 成長
- 最初は **ファイター** → **コルベット** → **フリゲート** → **デストロイヤー** → **バトルシップ** と進化（艦級。`TODO.md` §4-1 の艦級×艦種マトリクスと同じ）。
- 戦闘で **金（SCR）** を稼ぎ、アイテム・武器を買う。**相手の艦から奪う**（鹵獲・戦利品）こともできる。
- 強くなったら、より稼げる戦闘へ。稼ぎ → 強化 → より難しい戦闘、の循環。

### 1-2. カスタム（EVE・セカンドギャラクシー級の深さを目標）
- 今は **武器の種類**（実弾/ミサイル/ビーム＋種類違い）と **部品（ドラフト）** だけ。
- ゆくゆくは:
  - **艦に備え付ける砲台（ハードポイント）単位でカスタム**し、**そこに装填する弾も選ぶ**（砲台ごとに武器・弾種・向き）。
  - **エンジン・演算チップ**（センサー・AI・ハック耐性など）の等級と種類。
  - **ドローン**: 「戦闘機」という単純な括りをやめ、**グレード**（初級〜上級）や **ステルス機のような特徴のある機種**を用意する。
  - 部品・武器・ドローンは **グレード（N/R/SR/SSR）と勢力の特色**を持つ（勢力の技術で性格が違う）。

### 1-3. ワールドマップと勢力
- ワールドマップに **様々な勢力** がいて、エリア（宙域）を取り合っている。**戦闘の結果でエリアの持ち主が変わる**。
- 最初は Armored Core のように **勢力からの依頼（契約）** を受ける。
- **どの勢力の依頼を受けるかで各勢力との友好度が変わる**:
  - 友好度が低い勢力の宙域へ行くと **襲われる**（賞金首・敵対）。
  - 友好度が高い勢力の宙域では **アイテムが比較的安価**に手に入る（ショップの価格・品揃えが変わる）。
  - 勢力どうしにも関係（同盟・敵対・不干渉）があり、ある勢力の依頼を受けると、その敵対勢力の友好度が下がる。

### 1-4. ロールプレイ（プレイヤーのバックボーン）
- 開始時に **背景（経歴）** を選べる: **傭兵 / 賞金稼ぎ / 犯罪者 / 退役軍人 / 脱走兵** など。
- 経歴で **初期の友好度・初期装備・使えるショップ・得意な依頼** が変わる（例: 犯罪者=闇市が使える・多くの勢力から敵視 / 退役軍人=元の勢力と友好・装備が良い）。
- **最初からどこかに所属**してもよいし、**フリーランス**でもよい。

### 1-5. ゴール（長期）
- お金を貯めて艦を強くし、
  - **特定の勢力の中で出世して、自分の拠点を持つ**、または
  - **フリーランスとして、どこかの拠点を攻め落として奪う**
  のどちらでもよい。拠点を持つと、そこで補給・整備・生産ができ、収入になる（維持費・防衛戦もある）。

### 1-6. 今のゲームとのつながり（実装の土台）
| キャンペーンの要素 | 今ある土台 |
|---|---|
| 艦種・艦級 | 攻撃型/潜航型/空母型（`WEAPON_TYPE_CAP`・`DEFAULT_LOADOUT`）→ 艦級を足す |
| 武器・弾のカスタム | 武器の種類（`WEAPON_VARIANTS`）・積み込み画面 |
| 部品 | ドラフト式の部品（`PARTS`）・レア度 |
| ドローンのグレード | `DRONE_SPEC`（種類ごとの耐久・弾・威力）に等級を足す |
| 勢力ごとの見た目 | **第162弾で入れた勢力スキン**（`FACTIONS`・艦のスプライトを勢力で切替） |
| 敵の戦略・スキル | COMのスキル/性格（`STRAT_REG`・`SKILL_*`）→ 勢力ごとの「流儀」にできる |
| 試合の記録・リプレイ | 戦闘の振り返り（キャンペーンの戦闘もそのまま記録できる） |
| 拠点の奪い合い | コロニー/ノードの占有（試合内）→ ワールドマップ上の拠点へ拡張 |

## 2. 勢力（案）

勢力は **見た目で一目で分かる** ことを最優先にする（Star Citizen のメーカーごとのデザイン言語と同じ発想）。
車のたとえ: BMW / ボルボは**グリルを見れば一発でメーカーが分かる**。同じように、各勢力に **「署名（シグネチャ）となる形」** と **色** を決め、艦種（攻撃型・潜航型・空母型）が変わってもその署名を必ず入れる。

### 2-1. 今ある2勢力（スカーミッシュの味方側・敵側）

| | **ヘリオス連邦宇宙軍**（`helios`） | **鉄鴉団**（`crow`） |
|---|---|---|
| 立場 | 正規軍。秩序・規律。今の自艦側 | 海賊・私掠。荒くれ。今の敵艦側 |
| 色 | オフホワイト × グレー × **シアンの発光** | **黒 × ガンメタ × 赤** |
| 形 | 左右対称・直線的・整った装甲板・くさび形 | 非対称・溶接継ぎの増設装甲・使い込んだ傷 |
| **署名** | 艦体の中央を走る**シアンの発光ライン**と**青いエンジン光** | **赤い山形（逆V）の縞**と**赤く光るエンジン**（※爪状の艦首と赤い目の灯はキーアートの意匠。今のスプライトには無く、キャンペーン用に作り直す時に入れる） |
| 特色（ゲーム上の案） | バランス型・整備が良い・センサーが優秀 | 火力と奇襲に寄る・防御と探知は粗い |
| 流儀（COMの性格の傾向） | 標準・慎重（隊列・補給を重んじる） | 攻撃的・貪欲（奪う・突っ込む） |

### 2-2. キャンペーン用の勢力（4つ）

#### ① ヴァルキュル重工（`valkyr`）— 巨大企業・工業
- **立場**: 採掘・輸送・造船の巨大企業。自前の武装艦隊（警備艦隊）を持つ。金払いが良く、契約が多い。
- **色**: **チャコールグレー × 安全黄（セーフティイエロー）× 黒の警告縞**、エンジンは橙。
- **形**: **箱型のモジュールを積み上げた**船体・むき出しの鉄骨・クレーン・角ばった大きなエンジンブロック。
- **署名**: **黄×黒の山形（シェブロン）の警告縞**と、**艦首の幅広い平らなブルドーザーの刃（ブレード板）**。
- **特色（案）**: 耐久・積載・ドローン搭載が優秀 / 速さと隠密は低い。**部品と弾は安く大量**（経済力）。
- **流儀**: 慎重・貪欲（損失を嫌う・資源を取りに来る・拠点を固める）。
- **艦種の描き分け**: 攻撃型=重装の箱形砲艦 / 潜航型=細身でも警告縞つきの高速艇 / 空母型=積荷モジュールを積み上げた運搬空母。

#### ② サンクトゥム聖域教団（`sanctum`）— 宗教的な軍事教団
- **立場**: 「霧の聖域」を守ると称する信仰軍。規律は厳しく、教義に従わない勢力に容赦がない。
- **色**: **深い紫 × 磨かれた金の縁取り**、エンジンは紫がかったマゼンタ。
- **形**: **長く優雅な曲線の船体**・三日月形の艦首・左右対称で装飾的（金の透かし細工）。
- **署名**: **艦橋の上にそびえる金の光輪（ハロー・リング）のアーチ**と、**三日月形の艦首**。
- **特色（案）**: センサー・解析（演算力）・ハック耐性が優秀 / 武器は少なめ。**ハック・電子戦の技術**を持つ。
- **流儀**: 忍耐・知略（待ち伏せ・偽装・ハック）。
- **艦種の描き分け**: 攻撃型=大聖堂のような曲線の戦艦 / 潜航型=光輪の小さな細身の迎撃艇 / 空母型=光輪を戴く大聖堂型の母艦。

#### ③ ラストロード自由商船連合（`rustroad`）— 流れ者の商人・密輸業者
- **立場**: 宙域を渡り歩く商船団と密輸業者の寄り合い。どの勢力とも商売をする（中立・闇市に強い）。
- **色**: **錆びた茶 × オリーブ × 色あせた橙**の**つぎはぎ**、エンジンは温かい琥珀色。
- **形**: **非対称**・色も材質もバラバラの装甲板を溶接した**パッチワーク**・貨物コンテナを**縛り付けて**積む・高いアンテナ・パラボラ。
- **署名**: **船体に縛り付けた橙のコンテナ**と、**艦首の大きすぎる投光器（フラッドライト）**、つぎはぎの色。
- **特色（案）**: 部品が**安い・珍しい物が出る**（闇市）/ 艦の性能は平均以下だが**積載とドローン**が多い。友好度が上がりやすい（誰とでも商売する）。
- **流儀**: 貪欲・知略（拾い物・偽装・罠・逃げ足）。
- **艦種の描き分け**: 攻撃型=コンテナを背負った武装商船 / 潜航型=密輸の高速艇 / 空母型=コンテナだらけの商船母艦。

#### ④ フォグボーン（霧生まれ）（`fogborn`）— ヒッグスの霧に適応した生命の艦隊
- **立場**: ヒッグスの霧の中で生まれ育った人々（または共生体）。艦は**造るのでなく育てる**。霧の外の勢力を警戒する。
- **色**: **深い瓶緑 × 黒**の甲殻、**青緑（ティール）に光る脈**。
- **形**: **直線が無い**有機的な船体・**マンタや鯨**のような流れる輪郭・**二股に割れた尾びれ**・砲塔でなく「砲嚢（ポッド）」。
- **署名**: **船体を走る発光する青緑の脈**と、**エラのような噴射口**、二股の尾びれ。
- **特色（案）**: **霧の中で強い**（濃いヒッグスで速い・見つかりにくい・霧に溶ける）/ 霧の外では弱い。艦は**自己修復**する。
- **流儀**: 隠密・忍耐（霧に潜む・待ち伏せ・奇襲）。
- **艦種の描き分け**: 攻撃型=厚い甲殻の大型生体艦 / 潜航型=細いマンタ形の高速体 / 空母型=鯨形の母体（エラ状の格納口）。

### 2-5. 勢力の「流儀」を COM に結びつける（実装案）
- COM の性格8軸（攻撃性・隠密性・貪欲さ・慎重さ・知略・電脳・統率・忍耐）の **既定値の偏り**を勢力ごとに持たせ、戦略/任務/スキルの選ばれ方が勢力で変わるようにする（例: フォグボーンは隠密・忍耐が高く、霧に潜む/待ち伏せが選ばれやすい）。
- 勢力ごとに **既定の積み込み・武器の種類・部品の傾向**を持つ（ヴァルキュルは重砲弾・大量のドローン、サンクトゥムはハック系・センサー系の部品…）。

## 3. 勢力スキン（第162弾で実装したもの）

- 試合の設定画面で、**自機と敵それぞれ**に勢力のデザインを選べる（既定 自機=ヘリオス・敵=鉄鴉団）。
- **同じ艦種なら勢力を入れ替えられる**（攻撃型・潜航型・空母型 × 6勢力）。性能は変わらない（見た目だけ）。
- **ドローンは2系統**: 味方系（白×水色）と 敵系（黒×赤）。新しい4勢力のドローンは、勢力の「系統」（ヴァルキュル/サンクトゥム=味方系・ラストロード/フォグボーン=敵系 など）に合わせて どちらかを使う（専用のドローン絵は未作成）。
- 将来、キャンペーンでは **勢力の艦を鹵獲して乗る**・**勢力に所属すると その勢力の艦の見た目になる** などにつなげる。

## 4. 未決（キャンペーンを作る時に決める）
- 艦級の具体的な数値・艦級ごとの武器の上限・砲台（ハードポイント）の数と形。
- 通貨（SCR）の稼ぎ方・物価・勢力ごとの価格差・修理費・維持費。
- ワールドマップの形（宙域の数・つながり・移動のコスト）と、宙域を取る/奪われる条件。
- 依頼の種類（護衛・襲撃・偵察・輸送の拿捕・拠点の防衛・暗殺…）と報酬・友好度の変化。
- 経歴（バックボーン）ごとの初期値。
- セーブ（ワールドの状態をどこにどう保存するか）。今の `saveGame` は戦歴とクレジットだけ。
- 各勢力のドローン・Tech・敵ミサイルの専用デザイン。
