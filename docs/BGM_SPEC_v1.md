# Dark Echo — BGM(楽曲)制作指示書(第1版)

> 対象リポジトリ: `s1-1985/Dark-Higgs`
> 目的: ChatGPT に BGM を作ってもらい、Claude(コード担当)がゲームへ組み込む。効果音(SE)は別紙 `docs/SE_SPEC.md`(すでに納品・組み込み済み)。
> 表記: 「**事実**」= ゲームのコードで確認した内容 / 「**推論**」= 確認していない見立て。

---

## 0. 最初に読むこと

### 0.1 ゲームの説明(音楽担当者向け)

ヒッグス粒子の霧が満ちた宇宙空間で、**潜水艦戦のように「先に相手を見つけて撃つ」**戦艦ゲーム。プレイヤーは艦内のソナー員のように、センサーで相手の方位を聴き、推理し、撃つ。画面は暗く、霧で視界が利かない。**音を出す者が負ける**世界で、静けさそのものが緊張を作る。1試合は 10〜30 分。ほとんどの時間は「静かに探している」状態で、見つかった時・撃ち合う時だけ急に熱くなる。

### 0.2 音楽の方向性

**「重厚・閉塞感・SF。派手に盛り上げるより、不安と緊張を持続させる」**。基準は次の3つ。

1. **宇宙世紀ガンダム系の劇伴の重み**: 低弦・金管の重い持続、静かな中の不穏なモチーフ、交戦での打楽器と合唱の厚み。ただし**明るい英雄的メロディは出さない**。
2. **潜水艦もの(Das Boot / Silent Hunter / The Hunt for Red October の緊張)**: 長い持続音、遠くの金属的な響き、ゆっくりした脈動。静かな場面は**ほぼ音楽と気づかない**くらいでよい。
3. **宇宙の孤独(Homeworld のアンビエント寄りの荘厳さ)**: 広い空間の持続和音、ゆっくり動く弦とパッド。

**禁止**:
- 8bit・チップチューン・レトロゲーム風。軽快なポップス・EDM・ロック調(ギターのリフ)。
- **覚えやすい明るいメロディ**(長く聴くと疲れる。モチーフは2〜4音の短い断片まで)。
- **歌詞のある声**。声を使うなら「アー」「オー」の無歌詞の合唱・女声ヴォカリーズのみ。
- 第三者の楽曲・既存作品の旋律の引用・サンプリング(権利の問題)。特定の作品の主題に**似せすぎない**(雰囲気の参考にとどめる)。
- 曲の途中で音量が大きく変わること(ゲーム側でクロスフェードするため、曲内は**ダイナミクスを一定に**保つ)。

### 0.3 効果音を邪魔しないこと(最重要)

このゲームでは **SE が情報そのもの**(ソナーの響き・警報・被弾・受信の音)。BGM がこれを覆い隠してはいけない。

- **中音域(500Hz〜2kHz)は常にスカスカに**。特に **1kHz 付近はソナーの基音が鳴る帯域**なので、持続音・主旋律を置かない(置くなら控えめに、短く)。
- 警報音(低い唸り・脈動)と被る**低域の脈動の連打**を避ける。サブベース(60Hz 未満)は薄く(スマホでは出ないうえ、爆発 SE と濁る)。
- 静かな場面ほど音数を減らす。**「無音に近い瞬間」を曲の中に作る**(ゲーム側がSEを聴かせる余白になる)。
- 交戦曲でも、打楽器は**拍を打ち続けず**、間を空ける。常時フル編成にしない。

### 0.4 全曲共通の音楽的な約束(クロスフェードのため)

ゲーム側が状況に応じて曲を**2〜4秒でクロスフェード**して切り替える。濁らず繋がるよう、**ゲーム内で流す曲(§3.2〜3.3)は全て次を守る**:

| 項目 | 指定 |
|---|---|
| 調 | **D(ニ)を中心音とする暗い調**(D ドリアン / D マイナー / D フリジアン混合可)。全曲 D の持続低音(ドローン)を基準にして**他の調へ転調しない** |
| テンポ | **60 BPM を基準**(静かな曲は 60、緊張は 60 のまま音数を増やす、交戦は **120 BPM**(60 の倍) まで可)。拍子は **4/4** |
| ループの長さ | 小節数は **12 小節(60BPM で 48 秒)** または **16 小節(64 秒)**。交戦(120BPM)は 24 または 32 小節(48 / 64 秒) |
| 拍位置 | 頭の小節の1拍目に必ず合わせる(切り替えを小節頭にそろえるため) |

## 1. ファイル仕様

| 項目 | 指定 |
|---|---|
| 形式 | **WAV(PCM 16bit)** |
| サンプルレート | **48 kHz** |
| チャンネル | **ステレオ** |
| ピーク | **トゥルーピーク −1dBFS 以下・クリップ禁止** |
| ラウドネス | 静穏・凪・待機系 **−26 LUFS 前後** / 受信・照射系 **−24 LUFS 前後** / 交戦系 **−20 LUFS 前後**(**最大でも −18 LUFS**。SE が上に乗るので BGM は小さめでよい) |
| ループ | **ファイル名に `_loop`**。ファイル長 = ループ1周。**繋ぎ目でクリックや音切れが出ない**(始端と終端を重ねて処理。**残響の尾が次の周回の頭へ自然にかぶる**ように書き出す) |
| ワンショット(スティンガー) | **尾込み**(残響・余韻を含めて自然に 0 まで)。頭の無音は 5ms 以内 |
| 命名 | 小文字・数字・`_` のみ。`<ID>.wav` |
| サイズの目安 | ステレオ 48kHz 16bit は 1秒あたり約 192KB。**WAV の総量は 300MB 以内**(ゲームには Claude が MP3 に変換して入れる。**ChatGPT 側で圧縮する必要はない**) |

## 2. 納品の優先度と進め方

- **P0**: 試合の中核の4曲(静穏・受信・照射・交戦)とタイトル。これだけでも状況に応じた切り替えが成立する。
- **P1**: 試合進行の節目(勝敗のスティンガー・凪・サージ・リザルト)。
- **P2**: 仕上げ(潜伏・輸送船・ドック・追加の変化)。
- 納品は **P0 → P1 → P2 の順**。各優先度で1回以上。

## 3. 曲の一覧と制作指示

### 3.1 状況の考え方(ゲーム側の切り替え)

**事実**: ゲームには、プレイヤーに**観測できる兆候**を表す段階がある(`playerExposureLevel`)。0 静穏(何も聞こえない)/ 1 受信(信号を聞いた)/ 2 照射(探信を受けた・火器管制の照準波を受けた)/ 3 攻撃(被弾した・ミサイルやビームのチャージを察知した)。ほかに周期イベントとして **ヒッグスサージ**(予兆8秒 → 探知が大きく縮退する12秒 → 高感度の6秒)と **凪**(予兆15秒 → 霧が晴れて遠くまで見える10秒)がある。

**BGM はこの「プレイヤーが観測できる兆候」だけで切り替える**(敵の内部状態は参照しない — ゲームの方針。**推論**: こうするとBGMが敵位置のネタバレにならない)。切り替えはヒステリシス付き(急に上がり、ゆっくり下がる)。

| 状況 | 切り替えの条件(ゲーム側) | 曲 |
|---|---|---|
| 静穏 | 兆候0。探索中 | `bgm_calm_loop` |
| 受信 | 兆候1(信号を聞いた・追跡中) | `bgm_contact_loop` |
| 照射 | 兆候2(探信・照準波を受けた=見つかった) | `bgm_alert_loop` |
| 交戦 | 兆候3(被弾・ミサイル/ビーム警報)。最後の攻撃から約12秒は維持 | `bgm_combat_loop` |
| 凪 | 凪の予兆〜終了 | `bgm_lull_loop` |
| サージ | サージの予兆〜終了 | `bgm_surge_loop` |
| 潜伏 | 静穏〜受信の間に、潜航または機関停止で霧/岩礁に隠れている | `bgm_hide_loop` |

下りるときは 交戦 → 照射 → 受信 → 静穏 と**一段ずつ、各30秒以上かけて**戻る(戦闘の余韻を残す)。

### 3.2 試合中の曲(ループ・P0〜P2)

| ID | 使われる場面 | 音楽の作り方 | 長さ | 優先 |
|---|---|---|---|---|
| `bgm_calm_loop` | **ほぼ全時間**。霧の中を静かに探している | **ほとんど音楽に聞こえない**。D の低い持続音(低弦またはパッド)が呼吸のようにゆっくり膨らむ。数十秒に1度だけ、遠くで金属質の響きや、2〜3音の短い断片が鳴る。拍の主張はなし。**中音域は空ける**。ここが一番長く流れるので**疲れない**ことが最重要 | 64秒(16小節・60BPM) | P0 |
| `bgm_contact_loop` | 信号を受信した・何かが居る気配。**まだ見つかっていない** | 静穏の持続音に**ゆっくりした脈動**(低い鼓動のような単音、1拍または2拍に1回、ごく小さく)が加わる。不協和な音(短2度・増4度)が1つ浮かんで消える。「聞き耳を立てている」感じ | 64秒(16小節・60BPM) | P0 |
| `bgm_alert_loop` | **探信や照準波を受けた=見つかった**。まだ撃たれていない。逃げるか構えるか | 緊張が一段上がる。低弦の**ゆっくりしたオスティナート**(2〜3音の反復、1小節単位)、金管の低い持続、遠い打楽器(ティンパニの弱打、金属の擦れ)。まだ爆発的ではない。**息を詰める**感じ。メロディは出さない | 48秒(12小節・60BPM) | P0 |
| `bgm_combat_loop` | **撃たれている・撃ち合っている**。最大の緊張 | **重く押し込む**。低い打楽器(大太鼓・タイコ)と金属打撃のリズム、低弦と低金管の重い和音、女声または混声の無歌詞の合唱が厚みを足す。**120BPM** の刻み。ただし**常時フル編成にせず、2小節に1度は音を引く**(SE を聴かせる)。ヒロイックな旋律は不要。**窮地を戦う**感じ | 48秒(24小節・120BPM) | P0 |
| `bgm_lull_loop` | **凪**: 霧が薄くなり、遠くまで見える10秒。いつもより「晴れて」、無防備でもある | 暗さを少し緩めた**広がりのある響き**。高い持続弦または倍音の多いパッドが開け、低音は薄くなる。**不安は残す**(安心させない)。霧が戻るにつれ静穏へつながるよう、終盤は音数を減らす | 48秒(12小節・60BPM) | P1 |
| `bgm_surge_loop` | **ヒッグスサージ**: 探知が効かなくなる(耳が潰れる)12秒+前後。周期イベント | **ざわつく・歪む・耳鳴りのような**質感。ホワイトノイズ寄りの上昇する持続、低域の不安定なうねり。周期的でない(ランダムに近い)。**音程感を弱める**(D の基準は低域に薄く残す)。予兆の8秒に向けて徐々に膨らむ構成 | 32秒(8小節・60BPM) | P1 |
| `bgm_hide_loop` | **潜伏**: 霧や岩礁に隠れ、機関停止して息を殺している | 静穏よりさらに**薄く暗く**。ほとんど音がない。ごく低い持続と、遠くの水滴のような(金属の)ごく小さな音。**呼吸音のような**ゆっくりした揺れ。生き物の気配を感じさせる | 64秒(16小節・60BPM) | P2 |

### 3.3 スティンガー(ワンショット)

曲の切り替えに合わせて短く重ねる。**尾込み**。D の調性に合わせる(§0.4)。

| ID | 使われる場面 | 音の作り方 | 長さ | 優先 |
|---|---|---|---|---|
| `bgm_st_contact` | 初めて信号を受信した瞬間(試合で最初、または長い静穏の後) | 低い持続の中に**不協和な一音**がふっと立ち、消える。小さく | 3〜4秒 | P1 |
| `bgm_st_alert` | 初めて「見つかった」と分かった瞬間(静穏〜受信 → 照射) | 低弦の重い一撃 + 金属の共鳴が尾を引く | 4秒 | P1 |
| `bgm_st_combat` | 交戦に入る瞬間(最初の被弾・ミサイル警報) | 強い打撃(大太鼓)+金管の重い一音+低域の衝撃。**SE の被弾と重なる**ので、**中音域は控えめ**で低域と高域の倍音で重さを出す | 3秒 | P1 |
| `bgm_st_clear` | 交戦が収まった(最後の攻撃から時間が経った)時 | 緊張がほどけるが**安堵させない**。低い和音が静かに沈み、静けさに戻る | 6秒 | P1 |
| `bgm_st_victory` | 勝利(敵を撃沈/全コロニー占有) | **重く荘厳**。勝利の高揚ではなく「生き残った」重み。低弦と金管の和音がゆっくり開き、合唱が静かに乗る。ファンファーレにしない | 10〜12秒 | P1 |
| `bgm_st_defeat` | 敗北(自艦の撃沈) | 暗く沈む。低い持続和音が崩れ、余韻の中に金属の軋みが残る。**救いを残さない** | 10〜12秒 | P1 |
| `bgm_st_convoy` | 輸送船(民間船)を識別した時 | 短い**変化のある響き**(好奇心・物資の匂い)。ほんの少し明るい色が混じる。ごく小さく | 3秒 | P2 |

### 3.4 試合の外(ループ・P0〜P2)

| ID | 使われる場面 | 音楽の作り方 | 長さ | 優先 |
|---|---|---|---|---|
| `bgm_title_loop` | タイトル画面・ロビー(出撃準備・艦種選択・ブリーフィング)。ゲームの顔 | **このゲームの世界を示す一曲**。D の低音に乗って、広い宇宙と霧、孤独と緊張が伝わる。**短い象徴的モチーフ(3〜4音)を1つだけ**持ち、ゆっくり展開する。荘厳だが重くしすぎず、ずっと流れていても疲れない。ロゴが映える | 80秒(20小節・60BPM) | P0 |
| `bgm_dock_loop` | ドック(部品の付け替え・積み込み計画) | 落ち着いた**整備・準備**の雰囲気。静かな機械の脈動、低い持続、控えめな電子音と金属質の響き。ここは緊張を抜き、考える時間 | 64秒(16小節・60BPM) | P2 |
| `bgm_result_loop` | 試合後の記録(リプレイ)・戦闘詳報の画面 | 戦いの後の**静かな回顧**。勝敗どちらでも合う中立の、物思いにふける響き。スライダーで時間を動かしながら見るので、**意味ありげに盛り上がらない** | 64秒(16小節・60BPM) | P1 |

## 4. 納品方法(Git)

| 項目 | 指定 |
|---|---|
| ブランチ | **`chatgpt/bgm-assets`**(`main` から作る) |
| 置き場所 | **`prototype/assets/bgm/`**(フラット。サブフォルダ不可) |
| 台帳 | **`prototype/assets/bgm/manifest.json`**(下記) |
| 触ってよい範囲 | `prototype/assets/bgm/` 以下のみ。`game.js` / `index.html` / `style.css` / `docs/` は編集しない |
| 納品の単位 | 優先度ごとに1回以上(P0 → P1 → P2) |
| 差し替え | 作り直す時は**同じファイル名で上書き** |
| (Git が使えない場合) | WAV と `manifest.json` を zip にまとめてオーナーへ渡してもよい(SE と同じ運用) |

### 4.1 `manifest.json` の書式

```json
{
  "version": 1,
  "tracks": [
    {
      "id": "bgm_calm_loop",
      "file": "bgm_calm_loop.wav",
      "duration_s": 64.0,
      "loop": true,
      "bpm": 60,
      "bars": 16,
      "key": "D",
      "lufs": -26.0,
      "peak_dbfs": -1.5,
      "notes": "低弦ドローン+遠い金属の響き。中音域は空けた"
    }
  ]
}
```

`id` は §3 の ID と**完全に一致**させる。`bars` と `duration_s` は、BPM と矛盾しないこと(60BPM・4/4 で 1 小節 = 4 秒)。

### 4.2 納品前の自己点検

1. WAV / 48kHz / 16bit / ステレオ。トゥルーピーク −1dBFS 以下・クリップなし。
2. ラウドネスが §1 の範囲に収まっている(静穏 −26 / 交戦 −20 LUFS 前後)。**交戦が静穏より 4〜6dB 大きい程度**で、大きすぎない。
3. **全曲の中心音が D** で、転調していない(クロスフェードで濁らないか、`calm` → `contact` → `alert` → `combat` を連続で重ねて聴いて確認)。
4. `_loop` を2周連結して聴き、**繋ぎ目でクリック・音切れ・不自然な無音がない**。
5. **1kHz 付近に主旋律・持続音が居座っていない**(ソナーの帯域を空けている)。
6. 静穏・潜伏曲が**旋律的になりすぎていない**(長く聴いて疲れないか)。
7. 無歌詞である。既存曲の旋律に似ていない。
8. `manifest.json` の `file` が全て存在する。

## 5. 組み込み(Claudeの作業・ChatGPTは考慮不要)

1. `fetch` + `decodeAudioData` のローダー(SE と同じ経路の別バス)。タイトルは先読み、他は遅延読み込み。ファイルが無い間は従来の合成の環境音(`amb_drone_loop` など)のまま。
2. 状況の判定(§3.1)に**ヒステリシス**をつけ、2台のデッキでクロスフェード(2〜4秒・小節頭に合わせる)。
3. **SE が鳴っている間は BGM を自動で少し下げる**(ダッキング。特にソナー・警報・被弾)。
4. BGM 専用の音量スライダーとオン/オフ(SE とは別)。既存の環境音(SE側の `amb_*_loop`)は BGM を流している間は止めるか、下げる。
5. COM対戦の観戦でも同じ状況判定で流す。
6. 音量バランスの聴感確認はオーナーが実機で行う(Claudeは音を聴けない)。

## 6. 現行の状況(事実・参考)

- 現在は **BGM は無い**。流れているのは SE 側の環境音ループ(`amb_drone_loop` / `amb_tension_loop`)のみ。ファイルが読めない時は合成の低いドローン。
- SE 音量スライダーは第68弾でロビーに追加済み(BGM 用は未実装)。
- 試合の長さは 10〜30 分。曲の切り替えは**頻繁ではない**(大半は静穏)ので、**静穏曲の聴き疲れの無さ**が体験を決める。
