# 本編の実験的3D描画（2026-11-28）

> 続報: 構造物・環境・霧・Tech姿勢の描画を追加。現在の範囲と未検証事項は [仕上げ分の記録](WORLD_3D_COMPLETION_20261128.md) を参照。以下はそれ以前の経緯も含む。

## 今回の仕様

- 起動時・通常時は従来の2D見下ろし。表示モードは保存しない。
- レーダーを押すと35度傾けた3D表示、もう一度押すと2Dへ戻る。
- レーダーの地点ジャンプ／ドラッグによるカメラ移動を廃止。ドラッグや複数指は切替と判定しない。
- 同じゲームループ・同じ戦闘・探知・COMを使う。別の試作画面や別のシミュレーションは作らない。
- モデル未対応の絵は元のスプライトで表示する。他勢力のモデルを流用しない。
- WebGL2非対応／描画基盤の失敗／コンテキスト喪失では2Dへ戻す。個別モデルの読込失敗はその種類のみ元スプライトへ戻す。敵視点リプレイも当面2D。

## ユニット対応（2026-11-28更新）

ヘリオス連邦・鉄鴉団・ヴァルキュル重工・ラストロード自由商船連合・サンクトゥム聖域教団・フォグボーンの攻撃型・潜航型・空母・戦闘機・哨戒機・Tech、各6種、合計36種を実スプライト由来のGLBへ置換する。自機・敵とも同じ対応表。ズームアウト時のアイコン表示は従来どおり。

`unit-models.js` で元絵のファイル名を厳密に対応付ける。Techの姿勢絵は同じ基本モデルを用いる。骨格による姿勢アニメは未実装。艦首・向きはモデル別に補正する。ラストロード空母・戦闘機は横倒しをrollで補正した後に寸法を測り、Techは高さを含む寸法で正規化する。ドローンの最低表示寸法と元の透明度を継承する。

描画可能かつ画面内になった種類だけ遅延読込（同時最大2件）。未読込／失敗時には既存スプライトを描く。種類別プールで形状・テクスチャを共有し、透明度用材質は個体ごとに保持する。破棄中に完了した読込も解放する。全36種の先行読込は行わない。

GLBの面数合計を260,012から107,283へ、容量を22.34 MBから11.90 MBへ削減。小型機は512px、艦・Techは1024pxのJPEGテクスチャ（元材質は不透明）。実機FPSの改善を示す値ではない。

追加24種は686,403→231,997三角形、48,862,364→25,505,168 bytes。全36種は339,280三角形／37,402,516 bytes。実機FPSの改善を示す値ではない。

元絵・生成ジョブ・軽量化・検証の詳細: [初回12種](UNIT_MODELS_20261128.md)／[追加24種](REMAINING_UNIT_MODELS_20261128.md)。

背景・霧・環境・構造物・射程・反応マーカーは既存Canvas描画を流用する。ワールド座標のY方向をcos(35°)で投影し、描いた画面をThree.jsの背景テクスチャとして使用する。その上に対応する艦の実モデルを描く。地形や霧そのものの立体化／ボリュームシェーダー化は今回の範囲外。

表示・入力・HUDの投影を揃えるため、`screenToWorld`、`worldToScreen`、ドラッグ量、追従中心、ビューポートとミニマップの枠を補正する。HUDの文字と操作ボタンは従来の画面座標で描く。

## 情報の扱い

3D側へ敵艦リストや真の位置を直接渡さない。既存 `Ship.draw` の有視界・発砲フラッシュ等の判定を通過し、実際に描くスプライトだけを `drawMobileSprite` で受け取る。

本流の第246弾の流体的な雲と第247弾のUI修正を取り込んだうえで、暗闇・雲のオフスクリーンマスクにも同じ俯瞰投影を適用する。

`stepWorld` と `Ship.draw` の可視性判定は変更していない。霧の濃度や探知範囲を見た目のために変更する処理は無い。自艦と既に描画可能になった艦は既存仕様と同じく霧の上に表示する。

## 実装

- `view3d.js`: 遅延読込・切替・エラー復帰。ゲーム状態への書き込みなし。
- `view3d-renderer.js`: Three.js描画、背景画面の転送、モデルの再利用。
- `vendor/three/`: Three.js r170とGLTFLoader、BufferGeometryUtils、MITライセンス。CDNに依存しない。
- 3D用の別requestAnimationFrameは作らず、既存renderWorldから1回だけ描く。
- 3D用のDPRは最大1.5。2Dだけで遊ぶ場合はThree.jsとGLBを読み込まない。

## 検証

```sh
node tools/test_view3d.cjs
node tools/test_unit_models.mjs
node tools/test_unit_geometry.mjs
node --experimental-vm-modules tools/test_unit_renderer.mjs
```

通常時の2D、投影と逆投影、ドラッグとレーダー枠（3画面寸法×3ズーム×2モード）、レーダーのタップ／ドラッグ／キャンセル／複数指／キーボード、および既存stepWorldとShip.drawの不変性を確認する。

ブラウザでは本編のロビー→鉄鴉団・攻撃型で出撃→レーダー操作を実施。検証ブラウザのWebGLが無効のため、3D読込を試みて2Dへ復帰し、その後もゲームが進行することを確認した。
軽量化済み全36 GLBをBlenderで再読込・俯瞰確認済み（初回12種＋追加24種）。対応表・面数・ハッシュ・遅延読込・失敗分離・破棄と、実際のGLBを読むCPU解析、Three実シーングラフでの向き・roll補正後の縮尺・プール・透明度を検証済み。ゲーム内の3D合成の目視、2D/3D往復時の見た目、スマホ実機のFPSは未検証。
