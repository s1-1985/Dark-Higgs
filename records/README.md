# 試合の記録 (解析用)

ゲームの「試合の記録」を1試合1ファイルで貯める場所。まとめて解析する: `node tools/analyze_records.js`

## 実機の試合を貯める
1. 試合が終わったら「試合の記録」画面の **保存** を押す → `darkecho_日時_自機-vs-敵_勝者_秒.json.gz` がダウンロードされる
2. そのファイルを `records/device/` に入れてコミットする（GitHubのWeb画面の「Add file → Upload files」でも可）。または会話に添付して渡す

> ブラウザから git へ直接 push はできない（公開サイトにトークンを持てないため）。

## ヘッドレスで一括生成する (サンドボックス用)
`python3 -m http.server 8099` を起動して: `node tools/sim_matches.js <自機艦種> <敵艦種> <自機性格> <敵性格> <分> <回数>` → `records/sim/`

## リプレイで見る (第87弾)
ロビーの **リプレイ ▶** → 一覧（`records/index.json`）から選ぶか、ファイルを開く。自機/敵の視点・霧・ヒッグス層・思考ログ・拡大縮小・倍速・出来事へ飛ぶ。
記録を足したら一覧を作り直す: `node tools/build_record_index.js`

**▶ プレイ画面で再生**（第88弾）: COM対戦の記録（2026-11-12 以降・`meta.seed`/`cfg`/`gs` を持つもの）は、同じ試合をいつものプレイ画面でもう一度動かせる。上の帯で **敵の席 / 自機の席** を切り替える（操作はできない）。敵の席では 敵の目の霧・敵が受けた自艦の信号（帯域ごと）・敵の方位の記録と推定円 が出る。版（`?v=`）が記録と違うと同じ試合にならない（ずれたら表示する）

**人の操作の試合も再生できる**（第156弾）: 2026-11-14 以降に人が操作して記録した試合は `meta.human`・`inp`（操作の記録: [フレーム, 関数名, 引数]）を持つ。▶プレイ画面で再生 → 同じ種で試合を始め、記録した操作を同じフレームに実行する（操作はできない）。**記録していない操作（ドックでの積み込みの編集 など）があるとずれる**。版（`?v=`）が違うと同じ試合にならない。画面の大きさが違うと、記録は世界座標なので移動は同じだが、リングや名札の位置は端末の画面に合わせて出る。

> 2026-11-14: 古い版の記録（`device/` と `sim/` の全部・約500MB）は削除した（再生できず、解析にも使わない）。git の履歴には残っている。

## 中身 (fmt 2 — fmt 1 も読める)
fmt 2 で追加: `hg`(霧の濃度 100×100 の base64) / `s` の敵に `es`(探知) `ex,ey,er`(敵が思う自艦の位置と幅) `hu`(任務:段階) `tg`(目標地点) `vr`(視界) / 自艦に `vr`・`q`(推定円) / `Z`(囮・ノイズ・偽コンテナ)。敵の思考ログは通常プレイでも記録する（画面には出さない）。

## 中身 (fmt 1)
`meta`(版・性格・艦種・エンジン・マップの傾向) / `result`(勝者・時間・耐久・死因・戦闘詳報) / `s`(1秒ごとの位置・耐久・状態) / `x`(5秒ごとの詳細: 速さ・エンジン・帯域・兆候・脅威・弾・任務・戦略・敵の推定の誤差・シグネチャ) / `ev`(出来事) / `th`(COMの思考ログ全文 [フレーム, 'p'|'e', 文])
